# CARTEVA-APP

Aplikasi pencatatan dan pengelolaan stok bahan baku untuk usaha catering berbasis Flutter.

## Deskripsi

CARTEVA merupakan aplikasi mobile yang dirancang untuk membantu pengelolaan persediaan bahan baku catering agar pencatatan stok lebih terstruktur, efisien, dan mudah dipantau.

## Teknologi

- Flutter
- Dart
- Supabase
- Google Authentication

## Getting Started

Untuk menjalankan project ini:

1. Pastikan Flutter SDK sudah terpasang.
2. Clone repository.
3. Jalankan `flutter pub get`.
4. Konfigurasikan kredensial Supabase sesuai pengaturan project.
5. Jalankan aplikasi dengan `flutter run`.
